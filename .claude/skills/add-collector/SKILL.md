# 수집기·플랫폼 추가

수집기는 이 도구에서 바깥 세계를 만지는 곳이다. 그래서 **송신하지 않는다는 것과 라이선스를 먼저 확인하고**, 로직은
테스트할 수 있는 순수 함수로 빼고, OS·USB 호출은 최대한 얇게 둔다. 배포 대상은 Windows 11과 macOS이고 리눅스 전용
경로는 만들지 않는다(AGENTS.md §2).

## 0. 이 단계의 일인가

`docs/STATUS.md`를 읽는다. BLE·Wi-Fi는 Phase 1, 센서·서버 모드는 Phase 2.5, SDR은 Phase 3, 6GHz
검증은 Phase 4다(설계 §9). 이후 단계면 `TODO(phaseN)` 스텁만 둔다.

## 1. 플랫폼 노트를 쓴다

`docs/platform/<수집기>-<os>.md`, 템플릿은 `docs/platform/README.md`. 공식 문서와 설계 §7·§11의 출처로 확인해 적는다.

- **송신 여부** — 이 API·장비가 무엇을 내보내는가. 허용 예외는 macOS BLE 능동 스캔과 OS Wi-Fi 스캔의 probe request뿐이다
  (AGENTS.md §3.1). **Windows BLE는 수동 스캔**으로 설정하는 방법을 적는다. 연결·광고·주입이 필요하거나, 장비(HackRF)의
  송신 명령을 써야 한다면 **여기서 멈춘다.** 블루투스 연결 패킷을 수집하는 장비는 다루지 않는다(사용자 결정 2026-11-16).
- **라이선스** — 함께 링크되는 C 라이브러리(libhackrf, SoapySDR 등)의 라이선스와 링크 방식. `cargo deny`가 보지 못하므로
  노트에 적고 리뷰가 확인한다(AGENTS.md §3.7).
- 얻는 필드와 AGENTS.md §3.2 허용 목록의 대응. 플랫폼이 못 주는 것(macOS BLE 주소 → 호스트별 UUID)은 타입으로 드러낸다.
- 권한·서명·드라이버: Windows 정밀 위치(24H2), macOS 위치·블루투스 권한과 Developer ID 서명·사용자 세션, USB 장비
  드라이버. 권한이 없을 때 돌려줄 상태와 권한 온보딩·점검 모드에서 보여 줄 안내.
- 제약: 스캔 주기, 지원 대역(6GHz는 6E 칩), OS 버전별 차이(macOS 14/15/26 CoreWLAN).
- 확인하지 못한 동작은 "미검증"에.

## 2. 순수 변환 함수와 실패하는 테스트

원시 데이터 → `Observation` 변환(WLAN BSS 항목, CoreWLAN 네트워크, 광고 AD 구조,
FFT 빈 → 대역 전력)을 OS와 무관한 순수 함수로 설계한다. `test-author`에 맡기거나 직접:

- 입력 바이트는 테스트 도우미가 **사양대로 조립**한다. 실제 캡처나 실제 출력을 붙여넣지 않는다. 식별자는 합성 값만
  (MAC `00:00:5E:00:53:xx`, macOS UUID `Uuid::from_u128(작은 정수)`).
- 경계: 숨긴 SSID 두 표현, 잘린 IE, 길이 필드가 거짓인 AD 구조, 2.4/5/6GHz 채널 번호 겹침, RSSI 누락,
  macOS `HostLocal` UUID.
- 임의 바이트에 패닉하지 않는다는 `proptest` 속성.

돌려서 실패를 확인한다.

## 3. 얇은 OS·USB 어댑터

- `crates/collector-<종류>/src/sys/<os>.rs`에 `#[cfg(target_os = …)]`로 둔다. 하는 일은 OS·장비를 부르고 원시 데이터를
  2단계 함수에 넘기는 것뿐이다.
- FFI의 `unsafe`에는 `// SAFETY:` 논증을 단다: 핸들 수명, 버퍼 길이, 콜백 스레드, 해제 책임.
- 장비 USB 명령은 이름 있는 상수로 두고 문서 주석에 출처를 적는다. 송신 명령의 상수는 **정의하지 않는다.**
- 타임스탬프(`Timestamp`)는 수집기가 찍는다. 센서 모드에서는 NTP로 맞춘 시계와 서버가 알린 세션 시작 기준이다.
- 선택 기능(`sdr`)은 feature 뒤에 두고 기본 빌드에 시스템 라이브러리를 요구하지 않는다.

## 4. 상태를 보고한다

어댑터 없음, 권한 거부(위치·블루투스), 드라이버 미바인딩, 대역 미지원, 장비 분리, 스캔 실패를 서로 구분되는 상태값으로
돌려준다. 감독관 화면과 점검 모드에서 "Wi-Fi 수집 꺼짐 — 정밀 위치 권한 없음"처럼 보여야 하고, 권한 온보딩 화면이 고칠
방법을 안내한다. 한 수집기의 실패가 다른 수집기를 멈추지 않는다.

## 5. 수동 실측

실제 장비 테스트는 `#[ignore = "실제 장비 필요: <무엇>"]`로 두고, 사람이 `field-test` 스킬 절차로 돌린다. 에이전트는 송신 도구를 쓰지 않고, 결과
요약만 `docs/field/`에 기록하도록 돕는다.

## 6. 검토

`./scripts/verify.sh`. 그다음 **한 메시지에서, 새 세션으로** `compliance-auditor`(필수)와 `architecture-guard`를 병렬로 부른다.

## PR

PR 하나 = 수집기 하나 또는 플랫폼 하나. 제목 `ADD: <수집기> <플랫폼>`. 본문에 플랫폼 노트, 송신 여부, 라이선스, 쓰는
필드와 버리는 필드, 권한·드라이버 요구와 상태 보고, 테스트, 실측 여부와 미검증 항목을 적는다.
