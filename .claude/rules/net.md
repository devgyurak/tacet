# 센서↔서버 통신 요약

정본은 AGENTS.md §2 규칙 2·10·12와 §3.1·§3.3이다.

- net은 core 타입(`SensorReport` 등)을 직렬화해 나를 뿐 판정하지 않는다. 작업 공간 안에서 core에만 의존하고 OS별 `cfg`가 없다.
- 시험장 내부망 전용: mDNS로 서버를 찾고, 페어링 코드로 센서를 등록하고, TLS(서버 인증서 고정)로 통신한다. 인터넷으로
  나가는 경로를 만들지 않는다.
- 서버는 센서 보고서를 신뢰하지 않는다 — 페어링되지 않은 센서는 거부하고, 형식이 틀린 보고서는 버리고 기록한다. 패닉하지 않는다.
- 센서 시각은 NTP로 맞춘 시계와 서버가 알린 세션 시작 기준이다. 시각 어긋남을 감지해 상태로 보고한다.
- 페어링 코드·인증서·식별자를 로그에 찍지 않는다. 센서는 보낸 뒤 원본을 쌓아 두지 않는다.
- 센서↔서버 통신은 탐지용 송신이 아니다. 유선 LAN 권장, 무선이면 그 AP를 화이트리스트에 넣도록 안내한다.
- 테스트는 루프백에서만, 인증서는 테스트 코드가 만든다.
