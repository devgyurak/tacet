# 개발 도구 요약

정본은 AGENTS.md §3.3·§3.7이다.

- devtools는 macOS·리눅스 개발용이다: 관측 녹화·재생. 배포 앱에 들어가지 않고, 아무것도 devtools에 의존하지 않는다.
- 관측 녹화는 `.obslog` 확장자로 저장소 밖 경로에 쓴다. 캡처와 똑같이 추적하지 않고 대화로 읽지 않는다. 재생 결과는
  점수·위치 분해 같은 요약만 공유한다.
- Kismet DB(`.kismet`)도 캡처로 취급한다.
- 송신 도구를 부르지 않는다.
