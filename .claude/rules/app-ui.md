# 앱·화면·대시보드 요약

정본은 AGENTS.md §2 규칙 11–12와 §3.3–§3.5, §7(배포)이다.

- 감독관에게 보이는 문구(앱 창, 웹 대시보드, 권한 온보딩, `Info.plist` 사용 목적)는 한국어이고 언제나 "확인 필요"의
  어조다. 부정행위·적발·확정 같은 단정, 수험생·좌석 지목은 쓰지 않는다.
- 위치는 "추정 위치" + 신뢰도 + 근거(센서별 RSSI 중앙값)로 보여 준다. 신뢰도가 낮으면 인접 교실에도 알린다.
- UI는 판단하지 않는다. 임계치·신뢰도 계산·판정 로직은 core의 몫이다(프런트엔드 코드 포함). 감독관 문구는 core `explain`이
  쉬운 말로 만들고, 화면(`desktop/`)은 core가 보낸 무게(severity)·알릴 교실로만 고른다. 기술 용어는 개발자 모드에서만.
- 감독관 기본 흐름은 처음 설정(교실·5×5 자리) → 교실 보정 → 단독 모드다. 서버·센서·본부 화면 보기는 개발자 모드에서만 연다.
- 렌더러는 Node에 닿지 않는다(contextIsolation·sandbox·CSP). 남의 문자열(SSID 등)은 언제나 textContent로 넣는다.
- 화이트리스트(감독관 장비, 의료기기·보청기) 기기는 알림·상세 화면에 나타나지 않는다.
- 식별자를 원본 그대로 로그·파일·`Debug` 출력으로 내보내지 않는다. 세션 중 화면 표시만 허용, 저장은 세션 솔트 해시만.
  솔트는 app이 만들어 core에 값으로 넘긴다.
- 대시보드는 시험장 내부망에만 연다. 텔레메트리·크래시 리포트·클라우드 전송을 넣지 않는다.
- 수집기 상태(권한 없음·드라이버 없음·장비 없음)를 감독관과 점검 모드가 볼 수 있게 보여 준다.
- OS별 코드(권한 온보딩, 절전 방지)는 app에만 두고 dashboard에는 두지 않는다.
- 서명 인증서·키는 저장소에 두지 않는다. 시험 기간 중 자동 업데이트는 끈다.
- 바꿨으면 `compliance-auditor`를 부른다.
