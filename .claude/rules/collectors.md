# 수집기 요약

정본은 AGENTS.md §2 규칙 5–10과 §3(수동 감지·법·개인정보·라이선스)이다.

- **송신하지 않는다.** 주입, 디어스, 광고, BLE 연결·GATT, Wi-Fi 접속·호스팅, HackRF 송신 금지.
  예외는 macOS BLE 능동 스캔과 OS Wi-Fi 스캔의 probe request뿐이고, **Windows BLE는 수동 스캔**이다(§3.1).
- **해석하지 않는다.** BLE는 광고 메타데이터, Wi-Fi는 비콘 헤더만 쓰고 블루투스 연결 패킷은 다루지 않는다. SDR은 대역
  에너지에서 멈춘다(§3.2).
- 제3자 코드는 라이선스와 출처 없이 옮기지 않는다. `-sys` 크레이트가 묶어 오는 C 라이브러리 라이선스는 리뷰가 본다(§3.7).
- 수집기는 원시 데이터를 `Observation`으로 바꾸는 데서 멈춘다. 기준선·보정·점수는 core의 몫이다.
- 변환은 순수 함수, OS·USB 호출은 `sys/<os>.rs`의 얇은 어댑터. FFI `unsafe`에는 `// SAFETY:`.
- 실패는 삼키지 않고 구분되는 상태로 보고한다(권한 거부, 드라이버 미바인딩, 장비 없음) — 조용히 꺼진 수집기는 탐지 공백이다.
- 외부 바이트에 패닉하지 않는다. 테스트 입력은 사양대로 조립하고 식별자는 합성 값만(§3.3).
- 바꿨으면 `compliance-auditor`를 반드시 부른다. 절차는 `add-collector` 스킬.
