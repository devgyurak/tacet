# core 요약

정본은 AGENTS.md §2(아키텍처)와 §5(테스트)다. 여기는 이 경로에서 자주 걸리는 것만 모았다.

- core는 순수하다: IO, 시계, `async`, 난수, 출력, OS별 `cfg`, `HashMap`/`HashSet`이 없다.
  금지 크레이트 목록은 AGENTS.md §2 규칙 1.
- 판정(규칙·점수·기기 상관·위치 판정·신뢰도)은 여기에만 있다. 단독 모드와 서버 모드가 같은 코드를 쓴다.
- 시각은 `Timestamp(u64)`(세션 시작 기준 ms)로 받는다. `Instant::now()`를 부르지 않는다.
- 가중치·점수는 정수, RSSI 중앙값은 정한 규칙(짝수 개면 아래쪽), 동점은 (타임스탬프, 센서 ID, 수집 순번).
- **고정 dBm 임계치 금지.** 교실 보정값과 기준선 대비 상대 변화로 판정하고, 보정값이 없으면 "보정 필요".
- macOS `BleId::HostLocal` UUID는 다른 센서 관측과 같은 기기로 묶지 않는다. 신뢰도를 한 단계 낮춘다.
- 화이트리스트가 규칙 적중보다 앞선다(AGENTS.md §3.4).
- 규칙은 `docs/rules/` 노트에서 출발한다. 상수에는 출처와 노트 경로를, 실측하지 않은 값에는
  `TODO(field-unverified)`를 단다(AGENTS.md §3.6).
- 바꾸면 테스트가 따른다. 탐지 로직을 바꿨으면 `detection-reviewer`를 부른다.
