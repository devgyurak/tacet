# 테스트 요약

정본은 AGENTS.md §5와 §3.3이다. 테스트는 `test-author` 서브에이전트에 맡길 수 있다.

- 이름은 `given_<상태>_when_<동작>_then_<관찰값>`, 본문에 제어 흐름 없음, 모든 테스트가 단언한다.
- 기대값은 규칙 노트와 사양(Bluetooth SIG, Bluetooth 코어 규격, IEEE 802.11, 3GPP)에서 온다. 구현의 출력을 붙여넣지 않는다.
  고정 dBm을 기대값으로 박지 않고 테스트 교실의 보정값을 설정으로 준다.
- 합성 데이터만: 실제 캡처·녹화·식별자·외부 네트워크·하드웨어 없음. MAC `00:00:5E:00:53:xx`(랜덤 예시
  `02:00:5E:00:53:xx`), macOS UUID `Uuid::from_u128(작은 정수)`.
- 범위 안의 위협(설계 §3)은 양성 시나리오, 오탐 요인은 음성 시나리오, 옆 교실 기기는 "옆 교실로 배정"을 단언한다. 다교실 시나리오는
  센서 여러 대의 `SensorReport`로 만든다.
- 실제 장비가 필요한 테스트는 `#[ignore = "실제 장비 필요: <무엇>"]`.
- 스냅숏은 일괄 승인하지 않는다. 바뀌면 PR에 이유를 쓴다.
