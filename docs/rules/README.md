# 규칙 노트

탐지 규칙마다 노트 하나를 이 디렉터리에 둔다. 파일 이름은 `<규칙ID>-<영어-케밥>.md`
(`R5-hidden-ssid.md`, `R6-wifi-direct.md`)다. 다교실 위치 판정·교실 보정처럼 규칙이 아닌 판정
방식도 같은 템플릿으로 `L-<영어-케밥>.md`(`L-room-locator.md`)에 둔다. 규칙의 코드와 테스트는 이 노트에서 출발하고, 노트와 코드·테스트가 다르면 버그다
(AGENTS.md §3.6, `add-rule` 스킬).

노트는 한국어로 쓴다. 식별자 예시는 합성 값(AGENTS.md §3.3: MAC `00:00:5E:00:53:xx`·`02:00:5E:00:53:xx`)만
쓴다. 실측에서 본 주소·SSID·기기 이름은 적지 않는다.

## 템플릿

```markdown
# <규칙ID> — <한 줄 요약>

- 상태: 초안 | 구현됨 | 실측 확인됨
- 단계: Phase N
- 막는 위협: T# (설계 §3, T1–T7)
- 수집기·플랫폼: 어느 수집기가, 어느 OS에서 이 흔적을 주는지 (`docs/platform/` 노트)

## 흔적

이 위협이 남기는 무선 흔적과, 그것이 왜 시험 중 교실에서 이상한지.

## 조건

코드로 옮길 수 있을 만큼 정확하게. 필드, 비교 연산자, 경계 포함 여부.

| 필드 | 조건 | 비고 |
|---|---|---|
| `rssi` | `≥ 교실 보정 경계` (같으면 적중) | 고정 dBm 금지, 보정값 없으면 "보정 필요" |

## 쓰는 필드

AGENTS.md §3.2 허용 목록 안의 필드만. 받지만 버리는 필드가 있으면 적는다.

## 가중치

정수 기본값과 그 이유. 기본값을 바꾸는 것은 `decision` 이슈다.

## 근거

출처를 링크와 함께: Bluetooth SIG Assigned Numbers, IEEE 802 / 802.11, 3GPP 표, 제조사 문서.

## 오탐 요인

설계 §4.3의 요인마다 이 규칙이 어떻게 반응하고 무엇이 걸러내는지.

| 요인 | 반응 | 걸러내는 것 |
|---|---|---|
| 수거폰이 꺼지지 않음 | | 보관 위치 감점 |
| 옆 교실·복도 기기 | | 다교실 위치 판정으로 재배정 |
| 건물 밖 기기 | | 건물 밖 판정 감점 |
| 감독관 장비·의료기기·보청기 | | 화이트리스트(주소) |
| 랜덤 MAC 교체 | | 기기 상관 |
| macOS `HostLocal` UUID | | 시간 창 + 제조사 데이터 상관, 신뢰도 하향 |

## 경계

보정 경계와 같은 값, 보정값 없음, 기준선 창 끝(첫 관측 지연 포함), 표현이 둘 이상인 값(숨긴 SSID),
대역 간 겹치는 채널, 신뢰도 기준과 같은 RSSI 차이.

## 테스트

이 노트를 고정하는 테스트 이름(양성·음성·경계 시나리오).

## 미검증

실측하지 않은 값과 그 코드 위치(`TODO(field-unverified)`), 확인 방법(`docs/field/` 기록 계획).
```
