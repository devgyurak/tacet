# Tacet 로고 사용 안내

**아이디어:** 교실을 뜻하는 틀 안에, 신호가 보인 자리 하나. 판정이 아니라 "여기를 확인해 보세요"라는 뜻이다. 이름
Tacet은 악보의 "쉼"이다 — 시험 중에는 기기가 조용해야 한다.

## 파일

| 파일 | 쓰는 곳 |
| --- | --- |
| `tacet-symbol.svg` | 기본 표식. 밝은 바탕. |
| `tacet-symbol-reversed.svg` | 어두운 바탕. |
| `tacet-symbol-black.svg` | 한 색 인쇄, 도장, 팩스. |
| `tacet-symbol-small.svg` | 32px 이하(파비콘 등). 틀이 굵고 점이 크다. |
| `tacet-horizontal.svg` · `-reversed` · `-black` | 가로 배치(표식 + 글자). 기본 배치다. |
| `tacet-stacked.svg` | 세로 배치. 정사각형 자리에만 쓴다. |
| `tacet-app-icon.svg` | 앱 아이콘 원본. `desktop/build/icon.png`(1024px)로 내보내 electron-builder가 `.icns`·`.ico`를 만든다. |

## 짜임

- 256 격자 위에 틀 176(굵기 24, 바깥 모서리 반지름 14, 안쪽은 직각), 점 지름 44, 점 중심 (156, 100).
- 앱 바의 CSS 표식(`desktop/renderer/styles.css`의 `.brandmark`)은 같은 비율로 그린다. 표식을 바꾸면 둘을 함께 바꾼다.
- 글자 `tacet`은 굵기 22의 한 줄 획으로 직접 그렸다(글꼴 아님). 기준선은 틀 아래 변과 맞춘다.

## 색

| 이름 | 밝은 바탕 | 어두운 바탕 | 쓰임 |
| --- | --- | --- | --- |
| 먹 | `#191919` | `#ecebe6` | 틀과 글자 |
| 신호 | `#e96a26` | `#f07a3a` | 점 하나에만 |
| 아이콘 판 | — | `#1b1b1a` | 앱 아이콘 바탕 |

화면의 디자인 토큰(`--ink`, `--signal`)과 같은 값이다. 신호색은 점에만 쓴다 — 화면에서도 주황은 "확인 필요"에만 쓴다.

## 여백과 최소 크기

- 표식 둘레에 점 지름(44/176 = 한 변의 1/4)만큼 비운다.
- 기본 표식은 24px 이상, 그보다 작으면 `tacet-symbol-small.svg`를 쓴다. 가로 배치는 높이 20px 이상.

## 하지 말 것

- 점을 틀 밖으로 빼거나 다른 자리로 옮기지 않는다. 점 둘레에 물결·레이더를 더하지 않는다.
- 틀에 그림자·그러데이션·광택을 넣지 않는다. 주황을 틀이나 글자에 칠하지 않는다.
- 글자를 다른 글꼴로 바꾸거나 늘이지 않는다. "부정행위 탐지" 같은 단정 문구를 곁들이지 않는다(AGENTS.md §3.4).

## 남은 일

- 상표·이름 겹침 검색은 하지 않았다. 공개 배포 전에 한다.
