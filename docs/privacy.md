# 개인정보 처리방침 — Tacet

시행일: 2026-11-17

Tacet(시험장 무선 기기 탐지기)은 시험 중 교실에 나타난 휴대폰과 스마트 안경의 무선 흔적을 그 노트북에서 감지해 감독관에게
"확인 필요"를 알리는 데스크톱 앱이다. 이 문서는 앱이 무엇을 보고, 무엇을 저장하고, 무엇을 보내지 않는지 적는다. 근거가 되는
개발 규칙은 [`AGENTS.md`](../AGENTS.md) §3이다.

## 앱이 보는 것

운영체제가 알려 주는 주변 무선 신호의 겉정보만 본다.

| 무엇 | 예 | 쓰임 |
|---|---|---|
| 블루투스 저전력(BLE) 광고 | 기기 주소, 신호 세기, 제조사 번호, 서비스 번호 | 교실에 새로 나타난 기기 감지 |
| Wi-Fi 비콘 | 기지국 주소(BSSID), 네트워크 이름(SSID), 채널, 신호 세기 | 숨긴 핫스팟·휴대폰 핫스팟 감지 |
| 블루투스 기기 이름 | 광고에 실린 이름 | 교실 보정 때 감독관이 **자기** 휴대폰을 고르는 목록에만. 판정·알림·저장에 쓰지 않는다 |

- **통신 내용은 보지 않는다.** 기기에 연결하지 않고, 패킷 본문이나 휴대폰 통신 정보를 해석하지 않는다.
- **전파를 쏘지 않는다.** 예외는 운영체제가 스스로 하는 스캔 두 가지(macOS 블루투스 스캔 요청, 운영체제 Wi-Fi 스캔)다.
  블루투스 권한은 운영체제상 연결도 허용하는 권한이지만 앱은 광고를 **받기만** 하고 어떤 기기에도 연결하지 않는다.
- **사람을 알아내지 않는다.** 기기가 누구 것인지 알아내거나, 시험이 끝난 뒤까지 기기를 추적하지 않는다.

## 권한

| 권한 | 왜 |
|---|---|
| 블루투스 | 주변 BLE 광고를 받는다 |
| 위치 | Windows 11과 macOS는 위치 권한이 있어야 Wi-Fi 기지국 주소를 알려 준다. **앱은 위치(좌표)를 쓰지도 저장하지도 않는다** |
| 알림 | 창을 닫아 둔 동안 "확인 필요"를 운영체제 알림으로 알린다 |

## 저장하는 것

모두 그 노트북 안(앱 데이터 폴더)에만 저장한다.

| 무엇 | 내용 | 언제 지워지나 |
|---|---|---|
| 관측한 신호 | 위 표의 겉정보 | **메모리에만** 있고 감지를 끝내면 버린다. 파일로 쓰지 않는다 |
| 설정 | 교실 이름, 교실 안 노트북 자리, 교실 보정값 | 오른쪽 위 **설정 ▾ → 설정 초기화**, 또는 앱 데이터 폴더 삭제 |
| 예외 기기 목록 | 감독관이 직접 넣은 감독관 장비, 사전 신고한 의료기기·보청기의 주소. 이 기기에는 알림을 내지 않는다. **암호화하지 않은 파일**(`whitelist.toml`)로 저장한다 | 감독관이 개발자 모드의 예외 기기 목록에서 지우거나 앱 데이터 폴더를 지운다. 설정 초기화로는 지워지지 않는다 |
| 보고서 | 감독관이 저장을 누를 때만. 시각, 의심 점수, 적중한 규칙, 교실, 위치 신뢰도와, 세션마다 새로 만든 값으로 바꾼(해시) 기기 값이 들어간다. 원래 기기 주소는 남지 않는다 | 감독관이 앱 데이터 폴더의 `reports`에서 지운다. 설정 초기화로는 지워지지 않는다 |

앱을 지울 때 앱 데이터 폴더가 함께 지워지는지는 설치 방식과 운영체제에 따라 다르다(Microsoft Store 판은 보통 함께 지워지지만
아직 실제로 확인하지 않았다). 남기지 않으려면 지우기 전에 개발자 모드의 "앱 데이터 폴더 열기"로 폴더를 열어 지운다.

운영체제 알림에는 기기 주소·네트워크 이름 같은 식별자를 넣지 않는다(알림 센터가 기록을 남기므로).

## 보내지 않는 것

- **기본(단독 모드)에서 관측 데이터는 노트북 밖으로 나가지 않는다.** 클라우드 전송, 사용 통계, 원격 진단, 광고 추적, 크래시 리포트가 없다.
- 개발자 모드의 건물 단위 구성(교실 노트북 → 시험본부 서버)을 쓰면 관측이 운영자가 설정한 시험본부 서버로 간다. 이 구성은
  시험장 내부망에서만 쓰도록 설계했고, 서버나 대시보드를 내부망 밖에서 닿을 수 있는 주소로 열도록 설정하면 앱이 경고한다.
  인터넷으로 내보내는 기능은 없다.
- 앱은 업데이트 확인을 하지 않는다. Microsoft Store 판은 Store가 업데이트를 관리한다.

## 제3자

Tacet은 개인정보를 제3자에게 주거나 팔지 않는다. 앱을 내려받은 곳(GitHub, Microsoft Store, Apple 공증 서비스 등)이 운영하는
서비스의 개인정보 처리는 각 서비스의 방침을 따른다.
